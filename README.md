Una Landing Page estática para una panadería libre de gluten, construida puramente con **HTML5 y CSS3 Vanilla**. 

Este proyecto fue desarrollado como una práctica intensiva enfocada en dominar **CSS Flexbox**, posicionamiento de elementos (absoluto/relativo) y **Diseño Responsivo (Mobile First / Media Queries)** sin depender de frameworks externos como Bootstrap o Tailwind.

🔗 **[Ver Demo en Vivo Aquí] (PON_AQUI_EL_LINK_DE_GITHUB_PAGES)**

## ✨ Características Técnicas

- **Maquetación con Flexbox:** Uso extensivo de contenedores flexibles para alinear, distribuir y ordenar elementos dinámicamente según el tamaño de la pantalla.
- **Diseño 100% Responsivo:** Implementación de *Media Queries* (`@media`) para adaptar la interfaz a dispositivos móviles, tablets y pantallas de escritorio.
- **HTML Semántico:** Estructuración del contenido utilizando etiquetas semánticas (`<main>`, `<section>`, `<article>`, `<aside>`, `<header>`) para mejorar la accesibilidad y el SEO.
- **Posicionamiento Avanzado:** Uso de `position: absolute` y `relative` para superponer tarjetas de contenido sobre imágenes de fondo (Hero Section y Special Menu).
